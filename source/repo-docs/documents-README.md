# Documentation Index

This is the agent-friendly index for repository documentation. It is intentionally
short and task-oriented; detailed source-of-truth rules live in
[`documents/jp/Document-Governance.md`](jp/Document-Governance.md), with the
complete classification inventory in
[`documents/jp/Document-Inventory.md`](jp/Document-Inventory.md) and the
component spec authoring standard in
[`documents/jp/Requirements-Spec-Standard.md`](jp/Requirements-Spec-Standard.md).
The Japanese document map is [`documents/jp/README.md`](jp/README.md).

## Authority

- `documents/jp` contains the Japanese source-of-truth documents across
  Protocol, Protocol Governance, Contributor, and Foundation domains. It is not
  a single specification artifact.
- `documents/en` is an English translation/support tree.
- `documents/public-docs` is the authoring source for public GitBook content.
  Its Japanese tree is derived from `documents/jp`; its English tree mirrors the
  public Japanese tree. The separate `deltaforesight/jpydf-docs` repository is a
  generated publication mirror and is not an authoring source.
- `documents/jp/engineering/historical-reviews` and
  `documents/en/engineering/historical-reviews` contain dated snapshots. Do not treat those
  files as current requirements unless the current spec or ledger points to them.
- Root [`../README.md`](../README.md) is inherited Liquity v2 background and is
  not the best entry point for JPYdf implementation decisions.
