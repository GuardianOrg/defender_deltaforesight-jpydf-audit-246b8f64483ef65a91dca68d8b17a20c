# Engineering Documents

This folder contains implementation plans, technical guides, verification ledgers, and point-in-time review evidence used by JPYdf contributors.

> The Japanese [`documents/jp/`](../../jp/) tree is normative. Protocol specifications live under [`../protocol/product/`](../protocol/product/), launch artifacts under [`../protocol/launch/`](../protocol/launch/), and DeltaForesight-specific commitments and operations under [`../contributors/deltaforesight/`](../contributors/deltaforesight/).
> Future initiative candidates and reevaluation gates are managed in the Japanese [`Roadmap.md`](../../jp/protocol/roadmap/Roadmap.md).

## Folder Layout

Permanent engineering materials are grouped by artifact type. Dated reviews and verification snapshots are isolated under [`historical-reviews/`](historical-reviews/).

| Subfolder                      | Category              | Contents                                                                          |
| ------------------------------ | --------------------- | --------------------------------------------------------------------------------- |
| [`plans/`](plans/) | Plans | Forward-looking implementation plans and progress trackers |
| [`guides/`](guides/) | Guides / implementation specs | Local verification, deployment configuration, and audit support |
| [`verification-ledgers/`](verification-ledgers/) | Evidence | Requirements-to-verification records |
| [`historical-reviews/`](historical-reviews/) | Historical / Evidence | Dated reviews, verification campaigns, and rebuild background |
