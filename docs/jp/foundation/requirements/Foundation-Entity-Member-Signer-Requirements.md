# Foundation Member / Operating Multisig Candidate Criteria

> **本書の役割**: Foundation Member / Foundation Operating Multisig Wallet の署名者候補、および別枠の nominee member provider 候補に対する due diligence 項目だけをまとめる。Day-1 構成、MINS、BOIR、OA、設立 Gate の正本は [`Foundation-Entity-RMI-DAO-LLC-Requirements.md`](./Foundation-Entity-RMI-DAO-LLC-Requirements.md)。
>
> **対象外**: Protocol Admin Multisig、Guardian、Treasury、PIL recipient、A-E protocol signer slots、protocol Safe address / threshold。

---

## 1. Scope

本書は、Foundation affairs に関与する候補を role ごとに評価するための checklist である。Member と Foundation Operating Multisig Wallet signer は別 role であり、候補は重複できるが一致を要しない。Foundation affairs とは、契約、IP / domain / docs、Foundation operating assets、grant / service payment approved under Protocol Governance、claim / litigation、Registered Agent 対応、BOIR / KYB / annual filing をいう。

Protocol parameter、contract owner、Timelock、Guardian、Treasury、PIL recipient の承認・実行は Foundation affairs に含めない。

---

## 2. Candidate Checks

| Area | 確認事項 |
| --- | --- |
| Role acceptance | 担当可能な role、責任範囲、fee、辞任・承継条件。 |
| Independence | DFKK / founder / affiliates の routine instruction に従わないこと、任免・署名指示を単独で受けないこと。 |
| Control domain | 同一 group / UBO / key holder / custody provider / signer operator の重複有無。 |
| Relationships / dependencies | investor、advisor、service provider、報酬依存、related-party status、service / grant counterparty 該当性。 |
| Compliance | 適用法、Registered Agent または RMI counsel が求める sanctions screening、KYB/KYC、good standing / corporate documents、annual update への協力。 |
| Operating multisig ops | Foundation affairs 限定、1 entity 1 address / 1 signer slot、rotation / replacement / lost key / compromise 対応。 |
| Records | Member identifier は非公開の executed Exhibit A に置く。Foundation Operating Multisig Wallet の public identifier、signer identifier / threshold は Initial Member consent / written designation、signer acceptance および implementation record に置く。holder identity、連絡先、signed independence evidence、control-domain disclosure、role / change history は access-controlled な Company records に置き、public repo に raw list や個人情報を置かない。 |
| Tax facts | [`Foundation-Entity-Japan-Legal-Tax-Analysis.md`](../evidence/Foundation-Entity-Japan-Legal-Tax-Analysis.md) のPE / CFC / 移転価格 / 寄附金 / 消費税の判定と再判定に必要な事実関係を提供できること。 |

## 3. Nominee-Provider Checks

MINS は 5 Member / operating signer とは別枠の nominee member provider 候補として、RMI Requirements の設立モデルに従う。候補確認では次だけを見る。

- MINS KYB と必要自然人 KYC に対応できるか。
- Nominee / authorized representative として BOIR / annual update および適用法上必要な filing に協力できるか。
- Membership Interest、Foundation Member voting right、経済権、veto、appointment right、protocol key および Foundation Operating Multisig Wallet 署名者 slot を持たず、OA Article V.4 に従い明示的に授権する Company Governance Approval の範囲でのみ行為することを受け入れられるか。

---

## 4. Open Confirmations

1. 候補別に公開可能な identifier と private evidence の切り分け。
2. Member set と別に承認する Foundation Operating Multisig Wallet の signer set / threshold / replacement rule。
3. 5 Member が membership のみで BOIR full KYC 対象にならない整理。
4. DFKKをMemberまたはoperating signerとして別途選任する場合のBOIR、非日本拠点・無代理の境界、related-party transaction controlsへの影響。
5. 各候補の受諾、sanctions screening、independence、fee、responsibility、indemnity。
