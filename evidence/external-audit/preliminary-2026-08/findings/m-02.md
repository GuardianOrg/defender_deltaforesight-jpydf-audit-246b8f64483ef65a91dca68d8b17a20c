## Reproduction and impact decision

`SkyUsdcSUsdsStrategy._estimatedTotalUnderlying()` always called
`previewUsdsToUsdc()`. Sky represents an explicitly halted USDS-to-USDC route
with `tout == type(uint256).max`, and the converter correctly reverts the
preview and execution paths in that state. The Vault could use its last measured
Strategy cache only until `strategyValuationMaxAge`; after that, backing pricing
became unavailable. `DFUSDCPriceFeed` classified the unavailable backing path as
an oracle failure and shut down the branch.

The report's root cause and Medium availability classification are accepted for
an activated Sky Strategy. The path does not transfer funds or overstate a
measured loss, but a routine route-control action could turn into terminal branch
shutdown after the cache window. Sky remains conditional/backlog and is absent
from the expected Day-1 Strategy set, so this is an activation blocker rather
than a currently configured Day-1 incident.

The pre-fix mutation run reproduced the report end to end:
`test_PriceFeedDoesNotShutDownBranchAfterHaltedRouteCacheExpires` failed when the
Strategy was restored to the report behavior and passed after remediation.

## Remediation

The converter interface now exposes the narrow state predicate
`isUsdsToUsdcRouteHalted()`. The concrete adapter returns true only when the
Sky wrapper reports the protocol-defined halt sentinel. Conversion and preview
continue to revert while halted.

For a tracked nonzero position:

1. an explicit halt values the Strategy at
   `min(oneToOneUsdc(position), principal)`;
2. unrealized sUSDS yield is therefore not recognized while no reverse exit is
   available;
3. the conservative value remains a live Vault measurement and does not expire
   into backing unavailability;
4. invalid fees, a failing route-status read, and every other preview failure
   continue to revert and use only the bounded Vault cache.

This is intentionally narrower than the report's suggested catch-all fallback.
A generic converter or quote failure is not evidence that Sky explicitly halted
the route; treating every revert as 1:1 could hide an invalid fee or dependency
fault and overstate backing.

The halt valuation still assumes USDS par. If USDS depegs while the reverse
route is halted, the value may exceed a secondary-market exit value even though
it cannot exceed tracked principal. M-02 cannot derive a trustworthy market
price from the halted venue, so this residual must remain an explicit Sky
activation assumption with depeg monitoring, allocation limits, and incident
response rather than being presented as solved by the principal cap.

## Side-effect review

- No storage variable, storage order, constructor, authority, or value-transfer path changes.
- The interface adds one read-only selector; all in-repository implementations and mocks implement it.
- Halted conversion remains impossible; the change affects book valuation only.
- A revert while reading halt status still fails closed rather than assuming halt.
- Invalid `tout > 1e18` remains an invalid fee, not a halt.
- Principal capping prevents yield recognition but does not price a USDS depeg during halt.
- The Strategy adds one wrapper fee read to nonzero valuation; work remains constant and transaction-bounded.
- JP normative requirements, EN support text, verification ledgers, and the Strategy incident runbook describe the new state boundary.
